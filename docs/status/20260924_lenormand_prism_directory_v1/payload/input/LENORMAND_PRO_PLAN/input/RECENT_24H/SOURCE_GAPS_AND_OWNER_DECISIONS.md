**OD-F-02 — 五牌本站语义。** 保持“现状/助力/阻力/隐藏变量/建议、第三张阻力兼中轴非独断”作为已要求的设计目标，不将本轮图纸冒充实际开放许可。未来需确认采用的具体方法、范围及版本；没有获准来源时只批准几何测试不等于批准牌义。

**OD-F-03 — 九牌方法与辅助对角。** 设计维持中心/周围/横纵主结构，对角仅辅助。是否采用某条具体作者的对角方法及作用域，必须在拿到真实来源后分别裁定；无对角许可不应阻断完整非对角主结构。

**OD-F-04 — 来源角色例外。** 默认保留 Matthews 结构/组合主干、Rana 日常信号补充。单条不要求双作者；也不能以 Rana 自动顶替缺失主干。只有未来确需改变来源角色时，才送爸爸裁定精确例外，不以当前缺书强迫现在决定。

**OD-F-05 — 实施与运行范围。** 未来代码任务、DB/provider/网络、模式开放须获各自明确授权。本次指令仅离线设计，不包含任何一种上述授权。
